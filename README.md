# Bestofarr

Self-hosted, Docker-contained web app that pulls artist "top tracks" from Deezer or Last.fm and creates matching playlists in [Navidrome](https://www.navidrome.org/), named `Best ofs/<Artist Name>`.

> Status: early development.

## Planned

- Fetch top tracks per artist (Deezer, Last.fm)
- Match tracks against your Navidrome library
- Create/update playlists via the Subsonic API
- Web UI, shipped as a single Docker image
